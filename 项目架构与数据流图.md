## 2) 核心时序图（init/start/scrape/filter/connect）

```mermaid
sequenceDiagram
    participant User as 用户
    participant CLI as CLI
    participant MC as MainController
    participant BM as BrowserManager
    participant SM as SearchManager
    participant EX as CDPExtractor
    participant DB as ContactManager/Database
    participant CF as ContactFilter
    participant SE as ScoringEngine
    participant LLM as LLMClient
    participant MK as Marketing

    User->>CLI: init
    CLI->>MC: initialize_system()
    MC->>DB: 初始化数据库/目录
    MC-->>CLI: 初始化完成

    User->>CLI: start
    CLI->>MC: start_browser_session()
    MC->>BM: setup_driver() + navigate_to_linkedin()
    BM-->>MC: 浏览器会话就绪

    User->>CLI: scrape --keywords --pages
    CLI->>MC: scrape_keywords()
    MC->>SM: search_people(keyword, max_pages)
    loop 每页
        SM->>SM: 页面健康检查/重试
        SM->>EX: execute_script 提取联系人
    end
    SM-->>MC: 联系人列表
    MC->>DB: add_contacts() 入库
    MC-->>CLI: 爬取统计

    User->>CLI: filter
    CLI->>CF: filter_contacts(contacts, requirements)
    CF->>SE: build_requirement_profile()
    SE->>LLM: 提取需求标签与增强
    CF->>SE: score_contacts_batch()
    SE->>LLM: 批量评分请求
    SE-->>CF: ScoringResult[]
    CF-->>CLI: filtered_contacts + stats

    User->>CLI: queue-connect
    CLI->>DB: enqueue_connect_requests()

    User->>CLI: connect
    CLI->>MK: connect_assisted_flow()/send_connection_requests()
    MK->>DB: 读取候选/写营销记录
    MK-->>CLI: sent/failed/skipped
```

## 3) 数据流图（raw → DB → processed → outreach）

```mermaid
flowchart LR
    A[LinkedIn 页面DOM] --> B[data/raw/_sessions/search_results_*]
    B --> C[contacts 表]
    C --> D[filter 评分]
    D --> E[data/processed/*filtered*.json]
    E --> F[queue-connect]
    F --> G[marketing_records 表 pending]
    G --> H[connect/email 执行]
    H --> I[marketing_records sent/failed/accepted]
    C --> J[export json/csv]
```

## 4) 批量打分关键配置

- `filtering.llm_batch_size`: 唯一批量人数配置（每次发送人数）
- `filtering.llm_score_bulk_max_tokens`: 批量评分请求 token 上限
